# Apple Inc. — Investment Research & DCF Valuation

## Overview

This project analyzes Apple Inc. from an investment management perspective.

The objective is to evaluate Apple's financial performance, growth prospects, cash generation, risks, and intrinsic value using fundamental analysis and a Discounted Cash Flow (DCF) model.

## Objectives

- Analyze Apple's historical financial performance
- Evaluate revenue and segment growth
- Analyze profitability and free cash flow
- Assess Apple's balance sheet
- Develop financial forecasts
- Build a DCF valuation
- Perform scenario and sensitivity analysis
- Develop an investment thesis

## Data Sources

The analysis is based primarily on Apple's SEC filings and investor relations materials.

## Final Output

The project will conclude with an investment view based on the analysis:

**BUY / HOLD / SELL**

> This project is for educational and research purposes.
